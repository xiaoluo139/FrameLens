## 影析 FrameLens v1.0.0

一个软件，解析全平台视频/图片，也能跟本地模型聊天。**Windows 与 Android 双端**，
安装包内已带完整模型与推理运行时——下载、安装、直接用，不需要再下载任何东西。

### 下载

| 平台 | 文件 | 大小 |
|---|---|---|
| Windows 64 位 | `影析FrameLens-桌面端-全内置.exe` | 1.58 GB |
| Android（arm64-v8a） | `影析FrameLens-手机端-全内置.apk` | 1.60 GB |

安装说明：

- Windows：双击 exe，一键安装（无需选择目录），装完直接打开就能用
- Android：把 apk 传到手机点安装；vivo/小米等会提示「外部来源应用」，
  勾选「已知晓风险」再点「继续安装」即可
- 打开后右上角显示「本地模型已就绪」表示模型已加载完成，可以直接解析或提问

### 功能

**全平台解析**

- 粘贴分享文本或链接，自动识别平台并展开全部清晰度
- 视频清晰度与图片/封面分成两个区域，每一条、每一张都有独立下载按钮
- 支持抖音、快手、B站、小红书、微博、西瓜、TikTok、YouTube、腾讯视频、优酷、
  爱奇艺、芒果TV、Vimeo、X、Instagram，以及任意公开网页里的视频
- HLS（m3u8）多码率自动展开；内置下载器支持断点续传、并发调度与分片合并

**本地模型对话与视觉理解（完全离线）**

- 随包内置 llama.cpp 运行时与多模态模型，启动即后台预热，不用等加载
- 多轮对话、流式输出、图片直接拖进对话窗口
- 自定义模型：可导入自己的 GGUF（主模型 + mmproj），在「模型中心」或「模型对话」页一键导入、切换、移除
- 模型自检、空闲自动卸载；全程离线，内容不出本机

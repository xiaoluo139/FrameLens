# 常见问题

## 模型相关

**一定要下载 MiniCPM-V 吗？**
不必，而且**目前不建议用 MiniCPM-V 2.6**：实测它在当前推理引擎版本下输出乱码
（模型中心里已标注「兼容性异常」）。

推荐 **Qwen2.5-VL 3B**（约 2.6 GB）：中文对话与看图都实测正常，
是当前的默认模型。内存紧张可以先用 SmolVLM 256M（约 300 MB）体验流程。

**怎么知道一个模型在我电脑上到底能不能用？**
模型中心对已安装的模型提供**自检**按钮（下载完成后也会自动跑一次）：
它会发一句极短的问题，然后判断回复是否像正常语言。
不通过的模型会直接标红并说明原因，不用等你聊了半天才发现是乱码。

**模型下载到哪里？会占多少空间？**
默认在用户数据目录（设置 → 关于里有完整路径），删除对应文件夹即可释放。
MiniCPM-V 2.6 Q4_K_M 约 5.3 GB（含视觉编码器），SmolVLM 256M 约 300 MB。

**下载慢或者失败怎么办？**
模型中心里把「模型下载源」切到国内镜像 hf-mirror.com。下载支持断点续传，
失败后重试会从中断处继续。

**明明有显卡，为什么默认用 CPU 跑？**
GPU 版运行时对驱动版本敏感，不匹配时进程会直接起不来。默认 CPU 保证装上就能用；
设置 → 模型与生成 里可以手动切 CUDA 或 Vulkan 提速。

**断网能用吗？**
能。运行时与模型下载完成后，解析与推理都在本机完成。
只有「解析新链接」这一步需要联网，因为要去抓取目标网页本身。

## 解析相关

**支持哪些平台？**
抖音、快手、B站、小红书、微博、西瓜、好看、腾讯视频、优酷、爱奇艺、芒果TV、
搜狐、Vimeo、X/Twitter、Instagram、TikTok、YouTube，以及任意公开网页里的视频。

**为什么有的链接解析不出来？**
常见原因有三类：需要登录才能看的私密内容、平台风控（隔几秒重试常常就好了）、
页面结构改版。失败时应用会在结果里写明原因，不会静默失败；
通用解析器仍会尽量提取标题、封面与可下载地址。

**B站为什么只给到 480P？**
这是 B 站对未登录用户的限制，不是软件的问题。应用会明确提示
「该视频实际提供到 1080P」，在设置里填入登录 Cookie 后即可获取更高清晰度。
另外 B 站是 DASH 流，视频轨和音频轨分开，界面会把音频轨单独列出。

**YouTube 点了下载没反应？**
YouTube 对直链做了签名保护，本机无法直接解密，应用会如实提示
「需要 yt-dlp 等工具」。标题、作者、封面、时长都能正常获取。

**B站下载下来没有声音？**
B 站是 DASH 流，视频轨和音频轨分开，界面里会把音频轨单独列出，
两条都下载后用任意工具合流即可。

**直链能分享给别人吗？**
通常只有几小时有效期，建议尽快下载。界面提供「复制全部信息」用于存档。

## 使用与隐私

**我的文件会被上传吗？**
不会。没有账号系统、没有云端服务，图片和视频只在内存里转成 base64 交给本机模型。

**视频理解为什么要抽帧？**
模型是逐帧理解的，抽关键帧后按时间顺序喂给它。这样不依赖 ffmpeg，装完就能用；
代价是精细动作识别不如原生视频模型。

**视频打不开或者抽帧失败？**
内置解码器支持 mp4(H.264)、webm 等常见格式。mkv、HEVC(H.265) 可能无法解码，
需要先转成 mp4。

## 其他

**能装到手机上吗？**
可以，而且手机端和电脑端现在能力一致：**全平台解析 + 本地模型对话/看图**。

两种安装包：

- **全内置版（约 1.7 GB）**：模型（SmolVLM2 2.2B）与推理运行时都打进 APK，
  装完开箱即用，**完全不需要联网**。首次进入对话页会把模型展开到应用目录（实测几秒）。
- **精简版（约 17 MB）**：只有运行时，模型在应用内一键下载（可选中文更好的 Qwen2.5-VL 3B）。

手机端推理是在设备上跑 llama.cpp，**完全离线**，不会上传任何内容。

**手机上点「下载」会存到哪里？**
走的是手机自带的下载管理器，文件保存到「手机存储 / Download」，
通知栏会显示进度与完成提示，用任何文件管理器都能找到。

**手机上装的时候提示「外部来源应用」怎么办？**
这是 vivo/小米等厂商对非应用商店安装包的拦截提示。
勾选「已了解应用的风险检测结果」再点「继续安装」即可。

**换电脑要重新下载模型吗？**
用**全内置版**就不用：`影析FrameLens-桌面端-全内置.exe` 已经把
模型和推理运行时都打进安装包（约 1.6 GB），装完即用，不需要再下载任何东西。

**第一次对话要等模型加载很久吗？**
不用。应用启动后会在后台把模型加载好，右上角状态变成「本地模型已就绪」就说明可以秒回；
手机端同样如此。加载进度会实时显示在状态栏。

**能商用吗？**
本项目代码 MIT，可自由使用。内置模型遵循各自原始许可
（MiniCPM-V 为 Apache-2.0 系，SmolVLM 为 Apache-2.0）。
解析功能请遵守目标平台的服务条款，只下载你有权保存的内容。
